- `deploy/sync-ncm-lm1b.sh` para comparar/copiar el código del repo al runtime

## Nota de despliegue

El unit instalado ejecuta desde `/home/kubuntu/ncm`; el ejemplo del repo
(`deploy/ncm-lm1b.service.example`) ejecuta desde `free-ai/local/ncm`. Mientras
se mantenga el unit actual, usar `sync-ncm-lm1b.sh check/apply` tras cambiar el
servidor. Cambiar el unit requeriría `daemon-reload` y reinicio, y no se hizo.
